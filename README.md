## Features

- Advanced MEL and Python automation scripts optimized for rapid polygonal modeling, batch scene cleanup, dependency graph optimization, and professional animation workflows.
- Custom rigging presets, controller libraries, and skinning weight templates for enhanced character articulation and rapid deployment of complex skeletal structures.
- Quick-switch macros and custom shelf configurations for seamless navigation between modeling, rigging, animation, dynamics, and rendering workspaces.
- Pre-configured rendering setups and material networks (Arnold, V-Ray, Redshift) with automated AOV management, denoising, and batch render queue routines.
- Comprehensive documentation and step-by-step setup guides for all included tools, script files, and modules.
- Integration examples and bridge scripts for third-party VFX and game engine ecosystems (e.g., Houdini, ZBrush, Unreal Engine, Unity, Nuke).
- System resource optimization configs for faster viewport playback, reduced RAM usage during heavy simulations (Bifrost, nCloth, XGen), and optimized GPU/CPU load balancing.
- Ready-to-use animation curve management and motion capture data processing routines with automated smoothing, Euler filter application, and cycle detection capabilities.

- Windows 10/11 (or macOS / Linux)

## Usage

To utilize the included resources, download the package using the link above and extract the contents to a local directory. Run the provided setup utility (`Setup.exe` or `Install.ps1` / `Install.sh`) to integrate the custom MEL/Python scripts, rigging presets, and shelf configurations directly into your Maya `scripts`, `prefs`, and `modules` directories. Follow the on-screen prompts to complete the configuration process. For detailed customization and advanced API usage, refer to the `GUIDE.md` file included in the archive.
